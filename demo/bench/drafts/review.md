# ทดลองให้ AI ร่างรายละเอียดจากรายการสินค้าที่ร้านมีแล้ว

ใช้ชื่อเดิมและรูปอ้างอิงสองรูปต่อรหัส รวมสามรหัส ส่งครั้งละหนึ่งสินค้าผ่าน Responses API โดยให้เขียนลักษณะที่เห็นในภาพเป็นภาษาไทย เก็บรหัสร้าน รหัสสินค้า และตำแหน่งรูปต้นทางคู่กับ [ร่างจากโมเดล](descriptions.json) ทั้งสามรายการรอร้านตรวจทานก่อนนำไปใช้

| สินค้า | ผลตรวจเทียบกับรูปอ้างอิงและคำบรรยายเดิม | ข้อความที่เสนอให้ร้านตรวจ |
| --- | --- | --- |
| เครื่องปั่นตั้งโต๊ะ | สีฐาน โถใส และฝาดำตรงภาพ คำว่า “จตุรัสท้องพระโรง” ใช้บรรยายสินค้าไม่ได้ หูจับดูโปร่งใส และสีน้ำเงินอยู่ที่ขอบปุ่ม | โถใสมีหูจับและฝาดำ ตั้งบนฐานสีเงิน ด้านหน้ามีปุ่มหมุนขอบน้ำเงิน |
| เตาไฟฟ้า | เห็นหน้าเตาสีดำ สี่ตำแหน่ง และปุ่มสี่ปุ่มตามร่าง AI จำนวนปุ่มเพิ่มจุดสังเกตให้คำบรรยายเดิม | เตาหน้าเรียบสีดำ มีวงเตาสี่ตำแหน่งและปุ่มสี่ปุ่มเรียงริมด้านหน้า |
| iPhone 13 Pro สีฟ้า | สีฝาหลัง จำนวนเลนส์ และกรอบกล้องตรงภาพ หน้าที่ของจุดขนาดเล็กที่ AI เรียกว่า “รูไมโครโฟน” ยืนยันจากภาพอย่างเดียวได้ยาก | ฝาหลังสีฟ้า มุมซ้ายบนมีเลนส์ใหญ่สามวงเรียงเป็นสามเหลี่ยมในกรอบสี่เหลี่ยมมุมมน |

จากการตรวจภาพครั้งนี้ 2 ใน 3 ร่างมีคำที่ควรแก้หรือตัดออกก่อนนำเข้าคลัง ตัวอย่างเพียงสามรายการใช้ทดสอบขั้นตอนร่างคำบรรยาย ยังไม่ได้วัดผลของร่างเหล่านี้ต่อความแม่นยำในการตรวจจับ

จากโฟลเดอร์ `demo/` รัน `node bench/drafts/generate.mjs` เพื่อสร้างร่างรอบใหม่ สคริปต์เรียก API สามครั้งและเขียน `descriptions.json` เมื่อครบทั้งสามคำตอบ บันทึกการตรวจทานข้างต้นอ้างอิงร่างครั้งแรกจาก `gpt-4.1-mini-2025-04-14` เท่านั้น [คู่มือภาพของ OpenAI](https://developers.openai.com/api/docs/guides/images-vision)
