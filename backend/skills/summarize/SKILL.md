---
name: summarize
description: Summarize supplied material into a short overview, key points, and any stated decisions or next actions.
---

Summarize the material the user supplies in their requested language or the language of the request. Lead with the main point and keep only details that affect the reader's understanding. Preserve names, dates, figures, and uncertainty as stated. Include decisions or next actions only when the source provides them. If the user asks for an executive summary, read `references/executive-summary.md` before writing. Ask for the material when the request does not include it.
